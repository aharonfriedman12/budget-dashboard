## 2. הגיליון (Backend)

### 2.1 לשונית `מעקב תקציב שבועי ויעדי פרישה` (עסקאות)
עמודות: A תאריך (dd/mm/yyyy) | B שעה | C קטגוריה | D תיאור | E סכום | F הערות.
H2/I2: תחילת/סיום החודש הנוכחי (לפי TODAY). Make כותב לכאן שורה לכל הוצאה.

### 2.2 לשונית `יעדים_חודשיים`
A חודש (טקסט `MM-YYYY`, נכתב עם גרש מוביל כדי שלא יהפוך לתאריך) | B סופר ומשק בית | C מסעדות ואוכל בחוץ | D קניות שונות | E חופשות ונופשים | F דלק ותחבורה | G סה"כ תכנון | H סה"כ בפועל.
**שורה אחת לכל חודש.** `סיכום_מצב` קורא את השורה *הראשונה* של החודש (VLOOKUP), ולכן האפליקציה מעדכנת שורה קיימת ולא מוסיפה כפולה. האפליקציה לא כותבת לעמודה H.

### 2.3 לשונית `סיכום_מצב` (החודש הנוכחי, A1:F6)
שורות 2–6 = 5 קטגוריות (סדר: מסעדות, קניות, חופשות, סופר, דלק). שמות עם רווח בסוף בחלק מהתאים — הקוד עושה trim.
- B יעד: `=VLOOKUP(TEXT(TODAY(),"MM-YYYY"), 'יעדים_חודשיים'!A:H, <col>, FALSE)`
- C בפועל: סכום עסקאות הקטגוריה בחודש הנוכחי
- D יתרה: B−C
- E ממוצע: `=IFERROR(INDEX(FILTER('ארכיון_ביצועים'!$F$2:$F, 'ארכיון_ביצועים'!$G$2:$G=EOMONTH(TODAY(),-2)+1, 'ארכיון_ביצועים'!$B$2:$B=TRIM($A2)), 1), 0)`
- F יתרה נגררת: אותה נוסחה עם עמודה `$E` של הארכיון

### 2.4 לשונית `ארכיון_ביצועים` (היסטוריה, נוסחאות בלבד — אין צילום מתוזמן)
שורה לכל חודש × קטגוריה, נבנית אוטומטית מכל חודש שקיים ב-`יעדים_חודשיים`.
A חודש | B קטגוריה | C יעד | D בפועל | E יתרה | F ממוצע 3 חודשים | G תחילת חודש (תאריך) | H סטטוס (סגור/פתוח/עתידי).

```
A2: =ARRAYFORMULA(FLATTEN(FILTER('יעדים_חודשיים'!A2:A, 'יעדים_חודשיים'!A2:A<>"") & LEFT('יעדים_חודשיים'!B1:F1, 0)))
B2: =ARRAYFORMULA(FLATTEN(LEFT(FILTER('יעדים_חודשיים'!A2:A, 'יעדים_חודשיים'!A2:A<>""), 0) & TRIM('יעדים_חודשיים'!B1:F1)))
C2: =ARRAYFORMULA(IF(A2:A="",, IFERROR(VLOOKUP(A2:A, 'יעדים_חודשיים'!A:F, MATCH(B2:B, TRIM('יעדים_חודשיים'!A1:F1), 0), FALSE), 0)))
D2: =MAP(A2:A, B2:B, LAMBDA(m, c, IF(m="",, LET(d, 'מעקב תקציב שבועי ויעדי פרישה'!A2:A, k, ARRAYFORMULA(IF(ISNUMBER(d), TEXT(d,"MM-YYYY"), SUBSTITUTE(MID(d,4,7),"/","-"))), SUM(ARRAYFORMULA((TRIM('מעקב תקציב שבועי ויעדי פרישה'!C2:C)=c) * (k=m) * IFERROR('מעקב תקציב שבועי ויעדי פרישה'!E2:E*1, 0)))))))
E2: =ARRAYFORMULA(IF(A2:A="",, C2:C-D2:D))
F2: =MAP(A2:A, B2:B, G2:G, LAMBDA(m, c, s, IF(m="",, IFERROR(AVERAGE(FILTER(D2:D, B2:B=c, G2:G<=s, G2:G>EDATE(s,-3))), 0))))
G2: =ARRAYFORMULA(IF(A2:A="",, DATE(VALUE(RIGHT(A2:A,4)), VALUE(LEFT(A2:A,2)), 1)))
H2: =ARRAYFORMULA(IF(A2:A="",, IF(G2:G<EOMONTH(TODAY(),-1)+1, "סגור", IF(G2:G=EOMONTH(TODAY(),-1)+1, "פתוח", "עתידי"))))
```
**כללים שהוחלטו:** ממוצע מחלק רק בחודשים שיש להם נתונים (עד 3). יתרה נגררת = יתרת החודש הקודם בלבד (לא מצטברת), **מוצגת כמידע ולא מתווספת ליתרה הזמינה**. בשורת חודש עתידי/פתוח הממוצע כולל 0/חודש חלקי — לא מוצג, כי `סיכום_מצב` תמיד קורא את שורת החודש הקודם.

## 3. הקוד

| קובץ | תפקיד |
|---|---|
| `app/api/budget/route.ts` | GET. קורא 4 לשוניות. `?month=MM-YYYY` לחודש שעבר (נתונים מהארכיון). מחזיר: categories (target/spent/left/avg/carry/pct), totals, recentTransactions (כל העסקאות, עם category), monthTransactions + monthTotal (חודש נבחר), currentMonth/nextMonth/selectedMonth/isPastMonth/availableMonths, targets לחודש הנוכחי והבא. חודשים מחושבים לפי שעון ישראל (השרת ב-UTC). |
| `app/api/next-month/route.ts` | POST `{month, targets}`. מוצא שורת חודש ב-`יעדים_חודשיים` ומעדכן אותה (A:G), אחרת מוסיף. מאמת קלט, מחזיר `mode: updated/created`. |
| `app/page.tsx` | כל ה-UI (קומפוננטת client אחת). |
| `app/layout.tsx`, `app/manifest.ts`, `app/icon.png`, `app/apple-icon.png`, `public/icon-*.png` | שם "תקציב אישי", PWA (הוספה למסך הבית), אייקון ₪. |

**פיצ'רים ב-UI:** ניווט בין חודשים (חיצים, מ-ספטמבר 2026 עד החודש הנוכחי; חודש עבר = "חודש סגור", בלי תובנה/פס זמן) · תובנה יומית מבוססת חוקים (סדר: חריגה ← צפי חריגה מהיום ה-7 ← מעל ממוצע ← חיובי) + שורת תקציב יומי · כרטיס קטגוריה: יתרה (או "חריגה" באדום), יעד, ממוצע חודשי, נגרר מחודש קודם · לחיצה על כרטיס = עסקאות הקטגוריה בחודש · "צפה הכל" = עסקאות החודש + סה"כ + אזהרה כתומה אם לא תואם לניצול (= עסקה בקטגוריה לא מוכרת) · חלון יעדים: חודש נוכחי/הבא, ממולא מראש, סה"כ חי, עדכון במקום · רענון אוטומטי בחזרה לאפליקציה (פעם ב-30 שניות לכל היותר) · חלונות ברוחב האפליקציה (max-w-md) עם קו מנחה מנוקד.

## 4. Make — תרחיש "Budget Tracker" (ID 6009888, צוות 2263472)
טלגרם Watch Updates ← **מסנן "רק אני"** (chat ID של אהרון) ← Gemini 2.5 Flash (סיווג ל-JSON: type EXPENSE/QUERY, expenses[{category, description, amount}], coach_message) ← Parse JSON (מנקה ```json) ← Router:
- **Expense:** Iterator ← Sheets Add a Row (תאריך = `formatDate(now)`) ← Array aggregator ← טלגרם: "✅ נרשם: {תיאורים} / 📂 {קטגוריות} / 💰 ₪{סכום}"
- **Query:** Sheets Get Range `סיכום_מצב!A1:F6` ← Text aggregator (שורה לכל קטגוריה) ← Gemini (מנסח תשובה מהמספרים, בלי לחשב מחדש, + קישור לדשבורד) ← טלגרם
- הגדרות: **Store incomplete executions = Yes** (שגיאה לא מכבה את התרחיש).
- עלות: ~9 קרדיטים להודעה (~300/חודש מתוך 1,000 בחבילה החינמית). **מגבלה: 2 תרחישים פעילים, שניהם תפוסים** (Budget Tracker + הזמנות אתר).

## 5. קטגוריות — מופיעות ב-5 מקומות
